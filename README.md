## 🇬🇧 English

### Project Overview

This repository contains the implementation and performance evaluation of a **Decision Tree Classifier**, a popular machine learning algorithm. The project is developed using Python and the `scikit-learn` library to solve classification problems and visualize complex decision rules within the data.

### 🎯 Goals

* Train a Decision Tree Classifier model on a specified dataset.
* Evaluate the model's performance using metrics such as **accuracy**, **precision**, **recall**, and **F1-score**.
* **Visualize** and interpret the model's decision structure and rules.
* Find the optimal model parameters using hyperparameter optimization (e.g., `GridSearchCV`).
